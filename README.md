## Projects

- **[Mockingbird](https://github.com/ruhan-sahasi/mockingbird)**: a voice mock interviewer that grades behavioral answers, and every score must point to words you actually said. Code runs the interview and Claude only writes the lines. 613 Python and 220 web tests pass in CI. Python, FastAPI, React, AWS Fargate, Claude API, Vapi.
- **[techval](https://github.com/ruhan-sahasi/techval)**: a command line tool that values US tech companies from SEC filings, Nasdaq quotes and Treasury yields. It scores its models against simple baselines and reports the losses: two of six scores beat the baseline, three tie, one loses. 2,255 tests pass in CI. Python, NumPy (neural networks written by hand), pandas, scikit-learn.
- **Vestige** (co-founder and CEO): an AI representative for each department of a company that answers from interviews with its key people and from the systems it already runs. First use: saving what a retiring maintenance expert knows, and code checks every knowledge card quote against the transcript. TypeScript, Hono, React, Supabase, Claude API, Vapi.
- **[worldcup-oracle](https://github.com/ruhan-sahasi/worldcup-oracle)**: live World Cup forecasts in Rust. A goal model and Elo ratings feed each match forecast, which updates as goals and red cards arrive, and a parallel Monte Carlo over the 2026 bracket gives title odds. 425 tests pass across 14 crates, and CI fails the build if forecast skill drops below a committed baseline. Rust, tokio, axum, rayon, Docker.
- **[UIUC Bustle](https://github.com/ruhan-sahasi/UIUC-bustle)**: a campus transit app that ranks walk and bus options by ETA from live MTD bus departures and GTFS ride times, with an optional Claude rerank that falls back to the ETA order. 162 backend and 280 mobile tests pass in CI. React Native (Expo), TypeScript, FastAPI, Postgres, Claude API.
